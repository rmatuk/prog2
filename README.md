El proyecto de la materia consiste en el desarrollo desde cero de una Web API. Tras la ideación, el análisis de los requerimientos y el modelado del proyecto, necesitaremos múltiples tecnologías para su implementación y deployment. En este site encontrarán contenido complementario a las clases de la materia para guiarlos con el stack tecnológico.

El material se encuentra alojado en: https://rmatuk.github.io/prog2
